# Task Workplace

React + Vite で構築したシングルページ型のタスク管理アプリです。  
1画面の中で、当日のタスク確認、期限切れタスク確認、完了タスク確認、カレンダーによる日付確認をまとめて行える構成を目指しています。
※現在はフロントエンド側だけ制作の段階です。近日中にCRUD とデータベース保存機能を実装予定

## 主な機能

- Todoの作成
- 日付ごとのタスク表示
- 期限切れタスク一覧の表示
- 完了タスク一覧の表示
- FullCalendar を使ったカレンダー表示
- カレンダーの日付クリックによる対象日切り替え

## 使用技術

- React
- Vite
- FullCalendar
- CSS

## このアプリで意識したこと

- 1ページ内で完結する業務アプリ風レイアウト
- 日次確認、遅延確認、完了確認を同時に見られるUI
- 今後のAPI連携、認証、分析機能を追加しやすい構成

## 今後の実装予定

- CRUD とデータベース保存機能を実装し、永続的にタスクを管理できるようにする（近日中）
- タグをテンプレート化し、タグごとの作業量や処理スピードを分析できるようにする
- ログイン認証とチーム管理機能を実装し、複数人でスケジュールを共有できるようにする
- 日報・週報の作成および履歴管理機能を追加する
- Gemini API を連携し、タスクの優先順位提案や週報要約を行うアドバイザー機能を実装する
